Project Description

This project demonstrates basic statistical analysis using the C programming language.

The program is designed to analyze an array of unsigned character data and calculate its minimum, maximum, mean, and median values. It also sorts the array in descending order and displays the results.

Project Files

stats.c – Contains the main function and implementations of the statistical functions.

stats.h – Contains function declarations and documentation.

README.md – Provides project information and instructions.

Compilation

Compile the program using GCC:

gcc -Wall -Werror -o stats.out stats.c

Execution

Run the compiled program:

./stats.out
